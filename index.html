INTERHIGH / GAME REVIEW

「勝ちたい」と
「勝ちに行く」は同じか

大敗の中で消えたものを、気持ちではなく
認知・行動・チーム心理から考える

インターハイ1回戦 振り返り

01 / GAME FACTS

試合で起きていたこと

試合の流れ

  • オフェンスミスが続く
  • カウンターで失点
  • 相手が自分たちの良さを発揮
  • 相手のシュート率が上昇
  • 30点差以上のワンサイドゲームへ

強く残った違和感

  • 20点差でもボール運びが遅い
  • 前からプレッシャーをかけない
  • リバウンドで先に触られる
  • ルーズボールを二人が見ている

「勝ちたい」という感じに見えなかった。

02 / THREE LEVELS

「勝ちたい」は、三つに分かれる

1

結果願望

勝てたら嬉しい。
負けたくない。

→
2

意図・覚悟

苦しくても、自分たちから
試合を動かす。

→
3

行動への変換

走る・当たる・飛び込む・
声を出す・要求する。

本人たちは、第一段階では嘘をついていない可能性がある。
しかし、第二・第三段階がコート上に表れなかった。
03 / MODE SHIFT

「勝つ試合」から
「終わるのを待つ試合」へ

勝ちに行くモード

どうすれば勝てるか

  • 点を取り返す
  • 流れを変える
  • 仲間を動かす
⇢

消化するモード

これ以上失敗しないように

  • 怒られない
  • 自分だけ目立たない
  • とにかく終わるまで耐える

勝利が「自分たちの行動で動かせる対象」ではなくなった。

04 / LEARNED HELPLESSNESS

「どうせ変わらない」が
行動を止める

失敗が続く
→
制御できない感覚
→
努力の低下
→
無力型の反応
20点差でゆっくり運ぶ。
それは「点を取り返す時間」ではなく、
「失敗せずに消化する時間」になっていたのかもしれない。
05 / MOTIVATION REVERSAL

成功を求めるより、
失敗を避け始める

接近

成功したい

勝つために仕掛ける

VS

回避

これ以上失敗したくない

責任を負うプレーを避ける

前から当たる → 抜かれるかもしれない 飛び込む → 裏を取られるかもしれない 仕掛ける → ミスになるかもしれない

失われていたのは、勝利への感情より、
失敗を引き受けてでも勝つ行動を選ぶ勇気。

06 / COLLECTIVE EFFICACY

「自分の一歩で変えられる」感覚

集団効力感がある

自分が行く

仲間も続く

自分の行動がチームを動かす

集団効力感が落ちる

誰かが行くだろう

自分が行っても変わらない

ここで頑張ってもどうせ次でやられる

全員が半歩ずつ待つ。
その半歩が重なると、チーム全体が止まって見える。
07 / TEAM COLLAPSE

チームコラプスの連鎖

オフェンスミス
↓
カウンター失点
↓
相手が乗る
↓
集団効力感が下がる
↓
守備の一歩が遅れる
↓
相手がさらに楽に打てる
↓
「もう止められない」が強化される

相手のシュート率上昇と、こちらの守備強度低下は、
同じ心理的循環の表と裏だった。

08 / ADOLESCENT DEVELOPMENT

高校生年代で起きやすいこと

感情

失敗・焦り・仲間の視線に強く影響される

判断

圧力下では、普段できる判断が安定しにくい

自己制御

長期目標に沿って行動を保つ力は発達途中

「高校生だから仕方がない」ではない。
劣勢時の行動は、平常時とは別に訓練する必要がある。
09 / THE GAP

内面の「勝ちたい」と
外から見える「勝ちたい」

本人たちの定義

  • 心の中では勝ちたい
  • 諦めたとは口にしていない
  • 最後までコートに立った

指導者が見る証拠

  • 苦しいときに速度を上げる
  • 身体を張る
  • 仲間に要求する
  • 自分から流れを変える

感情の有無ではなく、
感情を何によって証明するかのズレ。

10 / NOT A GENERATION LABEL

「今どきの子」で片づけない

淡泊だから　／　根性がないから　／　3年生なのに
見るべきは世代ではなく、
劣勢時にどの認知が起き、
どの行動が失われたか。

経験年数は、「自分たちで状況を変える経験」の質を保証しない。

11 / MESSAGE TO PLAYERS

選手に伝えるなら

今日、君たちが勝ちたいと思っていなかった、とは言わない。

でも、勝ちたいという気持ちと、勝つための行動は別のものだ。

今日考えてほしいのは、「勝ちたかったか」ではない。

「勝ちたいという思いを、どの行動で表すつもりだったのか」だ。

12 / THE CORE

今回の核心

劣勢になったとき、
自分たちの手で状況を変えようとする主体性が消えた。
問題は「勝ちたい気持ちがなかった」ことではない。
勝利願望を、再び行動へ翻訳する技術を持っていなかったこと。
13 / QUESTIONS

次に問うべきこと

  1. 点差が開いた瞬間、何を考えていたか
  2. 自分のプレーで流れを変えられると思っていたか
  3. 失敗しても攻めるか、失敗を避けるか
  4. 誰がチームの感情を立て直す役割だったか
  5. 劣勢時の「勝ちたい」は、どの行動になるのか
CONCLUSION

勝ちたい、では足りない。

苦しいときほど、
勝利願望を行動へ翻訳する。

行動が、チームの感情をつくる。
