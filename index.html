INTERHIGH / GAME REVIEW

「勝ちたい」と
「勝ちに行く」は同じか

大敗の中で消えたものを、気持ちではなく
認知・行動・チーム心理から考える

インターハイ1回戦 振り返り

01 / GAME FACTS

試合で起きていたこと

試合の流れ

  • オフェンスミスが続く
  • カウンターで失点
  • 相手が自分たちの良さを発揮
  • 相手のシュート率が上昇
  • 30点差以上のワンサイドゲームへ

強く残った違和感

  • 20点差でもボール運びが遅い
  • 前からプレッシャーをかけない
  • リバウンドで先に触られる
  • ルーズボールを二人が見ている

「勝ちたい」という感じに見えなかった。

02 / THREE LEVELS

「勝ちたい」は、三つに分かれる

1

結果願望

勝てたら嬉しい。
負けたくない。

→
2

意図・覚悟

苦しくても、自分たちから
試合を動かす。

→
3

行動への変換

走る・当たる・飛び込む・
声を出す・要求する。

本人たちは、第一段階では嘘をついていない可能性がある。
しかし、第二・第三段階がコート上に表れなかった。
03 / MODE SHIFT

「勝つ試合」から
「終わるのを待つ試合」へ

勝ちに行くモード

どうすれば勝てるか

  • 点を取り返す
  • 流れを変える
  • 仲間を動かす
⇢

消化するモード

これ以上失敗しないように

  • 怒られない
  • 自分だけ目立たない
  • とにかく終わるまで耐える

勝利が「自分たちの行動で動かせる対象」ではなくなった。

04 / LEARNED HELPLESSNESS

「どうせ変わらない」が
行動を止める

失敗が続く
→
制御できない感覚
→
努力の低下
→
無力型の反応
20点差でゆっくり運ぶ。
それは「点を取り返す時間」ではなく、
「失敗せずに消化する時間」になっていたのかもしれない。
05 / MOTIVATION REVERSAL

成功を求めるより、
失敗を避け始める

接近

成功したい

勝つために仕掛ける

VS

回避

これ以上失敗したくない

責任を負うプレーを避ける

前から当たる → 抜かれるかもしれない 飛び込む → 裏を取られるかもしれない 仕掛ける → ミスになるかもしれない

失われていたのは、勝利への感情より、
失敗を引き受けてでも勝つ行動を選ぶ勇気。

06 / COLLECTIVE EFFICACY

「自分の一歩で変えられる」感覚

集団効力感がある

自分が行く

仲間も続く

自分の行動がチームを動かす

集団効力感が落ちる

誰かが行くだろう

自分が行っても変わらない

ここで頑張ってもどうせ次でやられる

全員が半歩ずつ待つ。
その半歩が重なると、チーム全体が止まって見える。
07 / TEAM COLLAPSE

チームコラプスの連鎖

オフェンスミス
↓
カウンター失点
↓
相手が乗る
↓
集団効力感が下がる
↓
守備の一歩が遅れる
↓
相手がさらに楽に打てる
↓
「もう止められない」が強化される

相手のシュート率上昇と、こちらの守備強度低下は、
同じ心理的循環の表と裏だった。

08 / ADOLESCENT DEVELOPMENT

高校生年代で起きやすいこと

感情

失敗・焦り・仲間の視線に強く影響される

判断

圧力下では、普段できる判断が安定しにくい

自己制御

長期目標に沿って行動を保つ力は発達途中

「高校生だから仕方がない」ではない。
劣勢時の行動は、平常時とは別に訓練する必要がある。
09 / THE GAP

内面の「勝ちたい」と
外から見える「勝ちたい」

本人たちの定義

  • 心の中では勝ちたい
  • 諦めたとは口にしていない
  • 最後までコートに立った

指導者が見る証拠

  • 苦しいときに速度を上げる
  • 身体を張る
  • 仲間に要求する
  • 自分から流れを変える

感情の有無ではなく、
感情を何によって証明するかのズレ。

10 / NOT A GENERATION LABEL

「今どきの子」で片づけない

淡泊だから　／　根性がないから　／　3年生なのに
見るべきは世代ではなく、
劣勢時にどの認知が起き、
どの行動が失われたか。

経験年数は、「自分たちで状況を変える経験」の質を保証しない。

11 / TWO TRANSLATIONS

同じ言葉を、
監督と選手は違う行動へ翻訳していた

川﨑先生の翻訳

「勝ちたい」

  • 残り時間を見て、速く攻める
  • 外しても、すぐ次の守備へ移る
  • 相手を見つけ、身体を当てる
  • 抑える人・取る人を判断する
  • リスクを引き受けて流れを変える
同じ言葉 勝ちたい 冷静に
選手側の翻訳

「冷静にやる」

  • 慌てず、ゆっくり運ぶ
  • 無理なプレーをしない
  • これ以上ミスを増やさない
  • 自分が原因になる失敗を避ける
  • 試合を乱さず最後まで進める

気持ちの有無ではなく、
気持ちをどの行動へ翻訳したかが違っていた。

12 / THE VISIBLE GAP

翻訳結果の違いが、
「勝ちたい姿に見えなかった」へ集約される

監督が期待した姿 速く、冷静に攻め続ける 身体を張って取り返す 自分から試合を動かす
≠
コート上で見えた姿 ゆっくり運ぶ リスクを避ける 流れが変わるのを待つ
「勝ちたいと思っていなかった」のではない。
選手の翻訳結果が、監督の考える“勝ちたい行動”と一致しなかった。
13 / CONTEXT CHANGES MEANING

「冷静に」の意味は、
点差と残り時間で変わる

6点差

一度テンポを落として整える

慌てず、判断を整理し、一本を確実に取りに行く。

20点差

速く、しかし冷静に攻め続ける

時間が減る以上、速度を落とすこと自体が勝利から遠ざかる。

冷静≠ゆっくり

同じ言葉でも、状況に応じて
行動への翻訳を変えなければならない。

14 / THE REAL ACTION

「勝ちたいなら行動に移せ」の
“行動”とは何か

1 状況を見る 点差・時間・相手・仲間
→
2 意味を翻訳する 今の「勝ちたい」は何をすることか
→
3 行動を選び直す 速度・守り方・役割・リスク
行動とは、決められた動作のことではない。
その場に必要な具体策へ、自分で翻訳しようとすること。
15 / BASKETBALL SENSE

監督が見ている
「勝ちたい気持ちの継続」

見る

点差、残り時間、相手の勢い、仲間の状態を読む

翻訳する

「勝ちたい」「冷静に」を、その場の課題へ置き換える

選び直す

速さ、守り方、役割、声、リスクの取り方を変える

臨機応変、バスケセンス、自分で考えられる選手。
それらはすべて、状況が変わるたびに、勝つための行動を翻訳し直し続ける力と言える。
16 / MESSAGE TO PLAYERS

選手に伝えるなら

今日、君たちが勝ちたいと思っていなかった、とは言わない。

でも、勝ちたいという気持ちと、勝つための行動は別のものだ。

今日考えてほしいのは、「勝ちたかったか」ではない。

「勝ちたいという思いを、どの行動で表すつもりだったのか」だ。

17 / THE CORE

今回の核心

劣勢になったとき、
自分たちの手で状況を変えようとする主体性が消えた。
問題は「勝ちたい気持ちがなかった」ことではない。
勝利願望を、その状況に必要な行動へ翻訳し直す技術を、チームとして持っていなかったこと。
18 / QUESTIONS

次に問うべきこと

  1. 点差が開いた瞬間、何を考えていたか
  2. 自分のプレーで流れを変えられると思っていたか
  3. 失敗しても攻めるか、失敗を避けるか
  4. 誰がチームの感情を立て直す役割だったか
  5. 劣勢時の「勝ちたい」は、どの行動になるのか
TOTAL VIEW / FINAL MAP

今回の敗戦を、一枚で捉える

進むたびに、試合の現象から核心までが一本につながります。

出発点 「勝ちたいように
見えなかった」 大敗以上に残った違和感
1 勝ちたいの三段階 結果願望 → 意図・覚悟 → 行動への変換
2 試合モードの転換 「勝つ」から「失敗せず終える」へ
3 回避動機 成功を取りに行くより、失敗を避ける
4 集団効力感の低下 「自分が動いても変わらない」
5 チームコラプス ミス・失点・守備低下が循環する
6 劣勢時の技術不足 勝利願望を行動へ戻す共通手順がない
7 翻訳結果のズレ 監督は「速く・強く・自分から」、選手は「ゆっくり・失敗しない」と訳した
核心 主体性の喪失 自分たちの手で状況を変えようとする力が消えた
次の課題 「気持ちを持たせる」のではなく、
状況を読み、勝利願望を具体的行動へ翻訳し直す力を育てる。
