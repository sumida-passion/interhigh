# インターハイ敗戦分析・タップ展開版

一枚のフローチャートを、タップするたびに順番に表示するGitHub Pages用データです。

## 公開方法
1. ZIPを展開
2. 中のファイルをGitHubリポジトリのルートへアップロード
3. Settings → Pages
4. Deploy from a branch
5. 対象ブランチの / (root) を指定

## 操作
- 画面タップ：次を表示
- 右矢印 / Space / Enter：次を表示
- 左矢印 / Backspace：一つ戻る
- ↺：最初に戻る
- ⛶：全画面表示
- iPad：左右スワイプでも移動可能

## 表示順
1. 試合の現象
2. 「勝ちたい」の三段階
3. 勝ちに行く行動が出なかった要因
4. 監督と選手の翻訳の違い
5. 翻訳のズレが生んだ結果
6. 今回の核心
7. 今後の指導の方向性
8. 監督が選手へ伝えたいこと
9. 最終的に目指すチーム像
