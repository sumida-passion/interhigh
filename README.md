# 「勝ちたい」と「勝ちに行く」は同じか

インターハイ1回戦の振り返りをもとにした、GitHub Pages用のプレゼンテーションです。

## 公開方法

1. ZIPを展開します。
2. 展開した3ファイルをGitHubリポジトリのルートへアップロードします。
3. GitHubの `Settings` → `Pages` を開きます。
4. `Deploy from a branch` を選び、対象ブランチの `/ (root)` を指定します。
5. 表示されたURLを開きます。

## 操作方法

- 右矢印 / Space / Enter：次へ
- 左矢印 / Backspace：前へ
- Home：最初
- End：最後
- 画面右下の ⛶：全画面表示
- スマートフォン・タブレット：左右スワイプ

## ファイル

- `index.html`：スライド本体
- `style.css`：デザイン
- `script.js`：スライド操作


## 最終スライド

最後のスライドは一枚のマインドマップです。
右矢印・Space・Enterを押すたびに、周囲の要素と接続線が順番に表示され、
最後に「今回の核心」と「次の課題」まで一枚の中に完成します。


## 今回追加した中心テーマ

- 川﨑先生側と選手側で、同じ「勝ちたい」「冷静に」の行動への翻訳が異なっていたこと
- 「冷静＝ゆっくり」ではなく、点差と残り時間によって「速く、冷静に」へ翻訳を変える必要があること
- 「勝ちたいなら行動に移せ」の行動とは、状況を読み、必要な具体策へ自分で翻訳し直す過程そのものであること
- その翻訳結果のズレが、「外から見て勝ちたい姿に見えなかった」という監督の違和感につながったこと
