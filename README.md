# インターハイ敗戦分析プレゼン（確定仕様版）

## 動き
- 各内容は独立したHTMLブロック
- タップ1回：ブロックを中央に大きく表示
- 次のタップ：全体マップへ収める
- 1番は2分割
- 2番は3分割
- 3番は5分割
- 4番は「監督側1行 → 選手側1行」を8組繰り返す
- 最後に黒背景のエンディングへ移行
- エンディングもタップごとに文字が出る

## 操作
- タップ / 右矢印 / Space / Enter：進む
- 左矢印 / Backspace：戻る
- ↺：最初に戻る
- ⛶：全画面表示
- 左右スワイプ：進む・戻る
