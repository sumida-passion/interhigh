# 「勝ちたい」と「勝ちに行く」は同じか

インターハイ1回戦の振り返りをもとにした、GitHub Pages用のプレゼンテーションです。

## 公開方法

1. ZIPを展開します。
2. 展開した3ファイルをGitHubリポジトリのルートへアップロードします。
3. GitHubの `Settings` → `Pages` を開きます。
4. `Deploy from a branch` を選び、対象ブランチの `/ (root)` を指定します。
5. 表示されたURLを開きます。

## 操作方法

- 右矢印 / Space / Enter：次へ
- 左矢印 / Backspace：前へ
- Home：最初
- End：最後
- 画面右下の ⛶：全画面表示
- スマートフォン・タブレット：左右スワイプ

## ファイル

- `index.html`：スライド本体
- `style.css`：デザイン
- `script.js`：スライド操作
