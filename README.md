# インターハイ敗戦分析：ブロック構築アニメーション版

画像にマスクをかける方式ではありません。
すべてのブロックをHTML要素として作成し、次の動きで展開します。

1. タップすると、そのブロックが画面中央に大きく表示される
2. もう一度タップすると、全体マップ内の所定位置に入る
3. 次のブロックが大きく表示される
4. これを9ブロック繰り返す
5. 最後に全体フローチャートが完成する

## 操作
- 画面タップ / 右矢印 / Space / Enter：進む
- 左矢印 / Backspace：戻る
- ↺：最初に戻る
- ⛶：全画面表示
- 左右スワイプ：進む・戻る
