# インターハイ敗戦分析プレゼン（グループ展開修正版）

## 今回の修正
- 1番の2分割は、同じ大画面に2つを並べて順番に表示し、その後に全体マップへ戻る
- 2番の3分割は、同じ大画面に3つを並べて順番に表示し、その後に全体マップへ戻る
- 3番の5分割は、同じ大画面に5つを並べて左から順番に表示し、その後に全体マップへ戻る
- 4番は、監督側1行→選手側1行の順で一覧に追加する
- 5番以降は、各グループ単位で表示後に全体マップへ戻る
- 全体マップの左列と下段の高さ・配置を再設計し、はみ出しと重なりを修正
- 最後は黒背景のエンディング

## 操作
- タップ / 右矢印 / Space / Enter：進む
- 左矢印 / Backspace：戻る
- ↺：最初に戻る
- ⛶：全画面表示
- 左右スワイプ：進む・戻る
